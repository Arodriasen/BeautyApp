# Tocador

Inventario de maquillaje y cosmética para Android: alta por código de barras, caducidad tras abrir (PAO) con avisos, tonos, lista de deseos…

React Native + Expo (SDK 58), TypeScript, arquitectura DDD.

```bash
npm install
npm test             # tests del dominio
npm run typecheck
npx expo run:android # build de desarrollo en el móvil
```
